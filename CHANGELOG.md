# Changelog

## 0.0.1

- Initial release
- Managed Butter proxy lifecycle (auto-download, start, stop, restart)
- AWS credential management with profile selection (SSO, credential_process, static keys)
- Dynamic model discovery from Butter's `/v1/models` endpoint
- Streaming chat completions with tool call support
- Status bar with process state indicators
- Commands: Start, Stop, Restart, Show Logs, Edit Config, Select AWS Profile, Update Binary, Settings
